# 💰 Budget Manager - دليل التطبيق

## نظرة عامة

تطبيق إدارة ميزانية شخصية احترافي مبني باستخدام React Native و Expo SDK 57. يساعدك على تتبع دخلك ومصروفاتك، تحليل نمط إنفاقك، وإدارة ميزانيتك الشهرية بكفاءة.

---

## ✨ الميزات الرئيسية

### 1. 🏠 الشاشة الرئيسية (Dashboard)
- **بطاقة الرصيد**: عرض الرصيد الكلي مع تفاصيل الدخل والمصروفات
- **تقدم الميزانية**: شريط تقدم يوضح نسبة المصروفات من الميزانية الشهرية
- **عمليات سريعة**: أزرار سريعة لإضافة مصروف/دخل والوصول للسجل والإحصائيات
- **آخر العمليات**: عرض أحدث 5 عمليات مالية

### 2. ➕ إضافة عملية
- نوع العملية (دخل أو مصروف)
- إدخال المبلغ بالشيكل (₪)
- وصف اختياري للعملية
- اختيار الفئة (للمصروفات فقط):
  - 🍽️ طعام
  - 🚗 مواصلات
  - 🧾 فواتير
  - 🎮 ترفيه
  - 💊 صحة
  - 🛒 تسوق
  - 🎓 تعليم
  - ⚙️ أخرى

### 3. 📋 سجل العمليات
- عرض جميع العمليات المالية
- فلترة حسب النوع (الكل / دخل / مصروفات)
- حذف عمليات فردية
- معلومات تفصيلية لكل عملية:
  - المبلغ
  - الوصف
  - التاريخ
  - الفئة
  - الأيقونة الملونة

### 4. 📊 الإحصائيات
- **بطاقات ملخصة**: إجمالي الدخل والمصروفات
- **رسم بياني يومي**: مصروفات آخر 7 أيام
- **تحليل الفئات**: 
  - مصروفات كل فئة
  - النسبة المئوية من إجمالي المصروفات
  - شريط تقدم ملون
- **إحصائيات العمليات**:
  - مجموع العمليات
  - عدد المصروفات
  - عدد الدخل
  - أيام الاستخدام

### 5. ⚙️ الإعدادات
- **الميزانية الشهرية**: تعيين أو تعديل الميزانية
- **التفضيلات**: (قريباً)
  - الإشعارات
  - المظهر
  - اللغة
- **البيانات**: (قريباً)
  - نسخ احتياطي
  - حذف جميع البيانات
- **عن التطبيق**: معلومات النسخة والتطوير

## 🚀 كيفية التشغيل

### تشغيل على Expo Go (الهاتف)
```bash
node_modules\.bin\expo start -c
```

ثم امسح QR code باستخدام:
- **iOS**: تطبيق الكاميرا
- **Android**: تطبيق Expo Go

### تشغيل على الويب
```bash
node_modules\.bin\expo start --web
```

ثم افتح: http://localhost:8081

## 💾 تخزين البيانات

### AsyncStorage
يتم حفظ جميع البيانات محلياً على الجهاز باستخدام AsyncStorage:

- **الميزانية الشهرية**: `monthlyBudget`
- **العمليات**: `transactions` (مصفوفة JSON)

### البيانات المحفوظة
```javascript
{
  monthlyBudget: 5000,
  transactions: [
    {
      id: "1234567890",
      type: "expense",
      amount: 150.50,
      description: "تسوق من السوبرماركت",
      categoryId: "1",
      date: "2026-09-18T10:30:00.000Z"
    },
    // ...
  ]
}
```

## 🐛 حل المشاكل الشائعة

### مشكلة: التطبيق لا يبدأ
**الحل:**
```bash
# نظف cache
rm -rf node_modules .expo
npm install
node_modules\.bin\expo start -c
```

### مشكلة: Splash screen يتجمد
**الحل:**
تم حل هذه المشكلة في الإصدار الحالي. إذا واجهتها:
1. تأكد من وجود `expo-splash-screen`
2. تحقق من `SplashScreen.hideAsync()` في `App.js`

### مشكلة: البيانات لا تُحفظ
**الحل:**
تحقق من:
1. `AsyncStorage` مثبت
2. لا توجد أخطاء في Console
3. الـpermissions صحيحة

## 👨‍💻 التطوير

### إضافة فئة جديدة
عدّل `BudgetContext.js`:

```javascript
{
  id: '9',
  name: 'اسم الفئة',
  icon: 'icon-name', // من Ionicons
  color: '#hexcolor'
}
```

### تخصيص الألوان
عدّل الألوان في كل ملف screen حسب الحاجة.

### إضافة ميزة جديدة
1. أنشئ screen جديد في `src/screens/`
2. أضف route في `AppNavigator.js`
3. أضف logic في `BudgetContext.js` إذا لزم
