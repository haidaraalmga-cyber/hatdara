# 📱 كيف تفتح التطبيق على الموبايل

## ✅ Server شغال الآن!

```
Port: 8081
URL: exp://192.168.1.222:8081
```

---

## 🔍 طريقة 1: من Terminal (الأسهل)

1. **روح على Terminal** يلي فيه الـ Expo شغال
2. **شوف الأعلى** - في QR Code مرسوم بنقاط:
   ```
   ▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄▄
   █ ▄▄▄▄▄ █ ██▀▀▄▀▄██ ▄▄▄▄▄ █
   ...
   ```
3. **افتح Expo Go** على موبايلك
4. **امسح QR Code** من الكاميرا

---

## 🔗 طريقة 2: الرابط المباشر

**إذا ما اشتغل QR Code:**

### على Android:
1. افتح **Expo Go**
2. اضغط **"Enter URL manually"**
3. اكتب: `exp://192.168.1.222:8081`
4. اضغط **Connect**

### على iOS:
1. افتح **Expo Go**
2. اضغط **"Enter URL manually"**
3. اكتب: `exp://192.168.1.222:8081`
4. اضغط **Connect**

---

## ⚠️ مهم جداً!

تأكد إنو:
- ✅ **الموبايل والكمبيوتر على نفس الـ WiFi**
- ✅ **Expo Go مثبت** على الموبايل
- ✅ **Server شغال** (في Terminal)
- ✅ **Firewall مش عامل block** للـ port 8081

---

## 🚀 إذا ما اشتغل:

### 1. تأكد من الـ WiFi:
```bash
# شوف IP Address الصح:
ipconfig
```

### 2. جرب Tunnel:
```bash
npx expo start --tunnel
```
هيك بيعطيك QR Code يشتغل على أي نت!

---

## 📞 طريقة Tunnel (إذا WiFi مختلف):

إذا الموبايل والكمبيوتر مش على نفس الشبكة:

1. **أوقف Server الحالي** (Ctrl+C)
2. **شغل Tunnel mode:**
   ```bash
   npx expo start --tunnel
   ```
3. **امسح QR Code الجديد**

⚠️ **Tunnel أبطأ شوي بس بيشتغل على أي نت!**
