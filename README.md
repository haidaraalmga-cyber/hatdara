# 💰 Budget Manager - تطبيق إدارة الميزانية

تطبيق شامل لإدارة الميزانية الشخصية والعائلية مع واجهة ويب احترافية وتطبيق موبايل React Native.

## ✨ المميزات

### 🌐 تطبيق الويب (React + Vite)
- 📊 لوحة تحكم متقدمة مع إحصائيات تفاعلية
- 💸 تتبع المصروفات والدخل
- 📅 تقويم مالي لتتبع العمليات اليومية
- 🎯 إدارة الأهداف المالية مع شريط التقدم
- 🔄 المصروفات المتكررة (شهرية، أسبوعية، يومية)
- 📈 تقارير شهرية ومقارنات
- 👨‍👩‍👧‍👦 إدارة الميزانية العائلية
- 🧮 حاسبة القروض
- 🛒 قائمة تسوق ذكية
- 💱 دعم عملات متعددة
- 🌓 الوضع الليلي/النهاري
- 🔔 مركز الإشعارات
- 🎨 تصميم حديث مع تأثيرات متحركة

### 📱 تطبيق الموبايل (React Native + Expo)
- 🏠 8 شاشات رئيسية
- 🎯 نفس المميزات الموجودة في الويب
- 🎨 تصميم احترافي مع AnimatedBackground
- ✨ تأثيرات تفاعلية مع PressableButton
- 📂 Drawer Navigation
- 🎭 Emojis للأيقونات

## 🚀 التقنيات المستخدمة

### الويب
- React 18
- Vite 5
- Lucide React (أيقونات)
- Context API (إدارة الحالة)
- CSS Modules

### الموبايل
- React Native
- Expo SDK 57
- React Navigation (Drawer)
- React Native Reanimated
- React Native Gesture Handler
- Expo Linear Gradient

## 📦 التثبيت

### الويب
```bash
cd project\ 2
npm install
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

### الموبايل
```bash
cd BudgetMobileApp
npm install
npx expo start
```

امسح الـ QR Code من تطبيق Expo Go
